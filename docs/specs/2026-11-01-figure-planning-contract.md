# FigureSpec 推理规划契约（本地、mock）

日期：2026-11-01。用户已确认继续此范围及 P1 的无新增迁移兼容修复。本文件不是部署授权，也不新增真实模型调用、会员扣费或生产入口。

## 模块设计（实施前）

1. 输入为用户确认的单图 ID、期刊 inspired 风格、col_N 字段 ID/别名/类型/单位、目标与明确统计选项；不接受原始 CSV、样例值、数据哈希或脚本，不自动提取原始列名/患者标签。用户填写的别名、目标与参数标签仍需去标识化，不能保证任意自填文本无隐私信息。
2. 模型请求只含已审阅的元数据及固定输出契约。图型、风格、模板版本、单位和统计参数不能由模型覆盖；模型只建议字段角色映射。
3. 输出严格 JSON：字段映射草案，或已知参数路径组成的 needs_input；拒绝 Markdown、额外字段、未知 ID、类型不符及非有限数值。不修复畸形 JSON，不执行 Python。
4. 映射后确定性检查所需单位/选项；缺参数则要求用户补齐，不默认填 95% CI、阈值、分母或雷达轴范围。复杂数值/数据一致性仍由现有可信 Python 校验负责。
5. 本地代码附加本次数据 SHA-256 与可信版本，构成冻结 FigureSpec；用户再次确认后才进入真实 Worker 校验/渲染。草案不是“统计正确”或“已结算”的证明。
6. 共用现有模板角色与样式目录，先单独做行为不变的目录提取，再增加规划契约。不建新框架、不新增生产依赖。
7. 仅开发 harness 通过明确 mock 调用验证；没有默认网络 transport 或生产 API，故不能靠它绕过会员权限去调用付费模型。状态/数据改变后旧草案不得套用。
8. 测试覆盖 11 个已实现图型、缺项、错误/注入、类型/单位、版本/哈希绑定，以及真实 Python/Pyodide 对合成 FigureSpec 的接受/拒绝；不声称模型判断质量、降本或提速已实测。

## 本轮边界

原图下载授权、会员版本/结算、真实推理 LLM 适配和生产开放仍为后续切片。生成/修改成功每版1学分、下载额外0学分的既定规则不变。由于生产入口使用 DEV 硬门控，线上“数据统计图”仍显示“开发中”；不能仅修改标签或开关就宣称完整上线。

## 实际实现与复现

- `lib/figure/figurePlanning.ts` 提供两个纯边界：构造 metadata-only 的 system/user 请求、严格解析 JSON 映射并绑定本地数据哈希。模型不输出 FigureSpec 的版本/单位/统计值；代码从已确认输入组装冻结草案，不让“JSON格式正确”冒充数据正确。
- 11种单图、5种已有风格及手动直方图变体；多面板仍走已有独立入口，不让模型扩展为任意布局。首版规划参数限定为有限 JSON 数字，拒绝隐式字符串转换；原 CSV 的精确数值仍由 Python 读取，不通过 JS/模型计算或改写。已有手动 FigureSpec 支持的其他精确数值形式不被此模块替换。
- 已确认缺失参数只返回已知路径，如 `fields.col_2.unit`、`parameters.interval.ci_level`；无默认95%CI、区间推算、P值校正、日期解析、数据补零或隐式单位转换。实际区间端点、分母、轴范围和输入值仍由可信 Python 检查；该模块不声称独立覆盖所有临床统计规则。
- `services/figure_worker/browser_planning/` 为开发专用复现入口：metadata 确认→明确 mock 响应→冻结草案确认→真实同源 Pyodide Worker；没有默认模型 SDK transport、生产 API 或会员账户模拟登录。界面明确标注“mock only”。

复现：`npm run dev -- --host 127.0.0.1 --port 4319 --strictPort --open false`，打开 `/services/figure_worker/browser_planning/index.html`；Playwright run-code 运行该目录 `interaction-check.js` 的同一函数源码。工具若限制文件路径，使用 worktree 文件内容作为 code 参数，不加载原脏工作区的旧脚本。

## 实验记录（2026-11-01）

- 假设：只让模型建议已知字段映射，宿主锁定已确认的图型/单位/统计选项，再经可信 Python，可以形成有界输入输出接口；不能由此推论真实模型分类或规划质量。
- 配置：固定合成 CSV 与显式参数，无随机性。浏览器沿用固定 Pyodide314.0.7、Python3.14.2、Matplotlib3.10.8、NumPy2.4.6、Pillow12.2.0 和既有锁摘要；原生 Python 使用 uv.lock。没有真实患者数据或模型调用，TypeSafe/推理LLM调用次数均为0。
- 结果：11类合成 FigureSpec 均由真实 Pyodide 接受并渲染，五种风格轮换覆盖（不是55种全组合测试）；实际PNG均4204×2362、599.9988DPI。请求证据不含CSV/本地哈希；正常UI流程中的两步明确确认均已验证，但客户端可自行修改/绕过，不是权限凭证。缺单位/统计选项、未知列及脚本字段被阻止，取消/更换数据/更改目标后的迟到mock不回填。320/768/1024/1440px无横向溢出，外部/会员API请求与控制台错误为0。原始运行输出见 harness 的 `last-run.json`。
- 结果：47项规划契约测试涵盖11类图、5种风格、直方图变体、缺项、版本/哈希/字段绑定及注入负例；全量105文件705项JS/TS、原生Python120项通过（35.209秒）。这是正确性/契约回归，不是速度提升或真实LLM质量实验。类型、构建和17项资源检查通过，原有大chunk/混合导入告警仍存在。
- 结论：本地mock规划契约与真实渲染验收通过，不代表实际会员LLM调用、版本/学分结算、免费原图授权或上线完成。生产入口仍保持“开发中”。未验证中文字体、国内三网无代理访问、真实低内存设备或离线运行。

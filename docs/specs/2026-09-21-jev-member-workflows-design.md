# Jev 会员判断层与生成结果评估

日期：2026-09-21。状态：grill-me 产品决策已确认；工程接入与发布验证未完成。本文优先于 2026-09-20 数据作图设计中关于模型分工的旧描述，不表示已有代码满足这些规则。

## 1. 范围与职责

新增服务端 TypeSafe adapter，直连官方服务，固定模型版本；密钥只在服务端，禁止浏览器直连、静默改用 OpenRouter 或模拟结果。Jev 用于结构化判断，不写最终文本、不执行工具、不成为权限或安全边界。降本提速和准确性改善是待验证目标，不是承诺。

- 代码：解析、字数、空字段、数值约束、候选允许列表、身份、授权、预算、扣费与重试上限。
- Jev：论文语义结构预检、候选分类/关键词、量表初判、图型/期刊预设推荐、prompt 完整性与语义重试建议。
- 推理 LLM：复杂规划、写作、润色、完整盲审、争议复核和必要修订。
- Python：受控数据模板渲染。图像模型：科研示意图生成/编辑。

独立问题共享证据并合并请求；依赖上一答案的问题顺序调用。固定量表/问题集版本，校验返回类型、必需问题 ID、有限概率、允许标签及实际模型。评分等级不是正确概率，confidence 也不是准确率。

## 2. 会员、同意与隐私

仅会员执行模式启用 Jev。已登录但选择 BYOK 的请求完全不接入，不向 TypeSafe 额外发送论文或密钥。

首次发送前单独告知 TypeSafe 接收必要正文用于分类、评分及生成核查，并取得同意。记录用途/告知版本和时间；提供方或用途实质改变需重新确认。拒绝者保留原会员推理模型流程，不提供 Jev 评估/雷达图。Jev 专属免费分析规则不自动扩展为无限免费的旧 LLM 分析；旧流程费用必须明确显示。

论文预筛提供移除可识别身份信息后的必要原文上下文，优先完整正文；超长正文按章节处理，不静默截断后宣称完成。post-check 同时提供生成文本与相关原文，缺少证据必须允许无法判断。自动去标识不能保证匿名，上传端仍提醒用户去除患者身份信息。

数据图仅提供已确认的字段别名、含义、类型、单位、必要汇总与绘图目的，不发送患者级行、标识或自由文本单元格。日志不记录正文、提示全文或凭证；判断追踪可能敏感，按所属任务访问控制和保留策略管理，不能混入财务流水。

## 3. 基础分析与用量

会员点击分析后以 Jev 替代可结构化的昂贵分析调用：语义结构、研究类型、候选标签及四项初评。代码展示固定文案、可验证的原文定位与可编辑选项，不另调用 LLM 编写初评说明。缺失候选/不确定时让用户选择，不默认追加推理调用。

四项为报告完整性、方法描述充分性、结论与证据一致性、会议适配性。等级为充分、部分不足、明显不足，另有无法判断/不适用。未报告不等于未实施；不预测录用率，不给论文综合总分。后台预筛仍用于辅助生成，但不向用户展示原稿初评雷达图。

余额大于零且已同意的会员可免费发起 Jev 基础分析：每分钟最多 3 次、滚动 24 小时最多 30 次新分析。取消该 Jev 路径原有第三次分析扣 1 学分规则。相同正文、会议、规则/模型/问题集版本可复用所属用户缓存，不占分析额度；修改用户选项不必重调用。缓存不能跨账号泄露正文或结果。

超长正文分段仍计一次用户分析，但必须有服务端输入与调用总预算。服务故障不消耗每日额度，失败请求仍受短时防滥用限制；并发限额必须原子执行。显示剩余额度及恢复时间，不自动转收费。已成功预留学分的生成任务不因余额归零停止内部核查。

## 4. 摘要 post-check 与有限修订

推理 LLM 生成 → Jev 对照原文检查 → 有争议/明确风险时合并给推理 LLM 复核与必要修订 → 文本改变时再做一次 Jev 检查 → 交付。

检查范围：事实不一致、无依据补充、结论夸大、改变含义的关键遗漏。格式/字数由代码检查；措辞偏好不触发修订。证据不足不直接判为错误，也不算通过。

每次生成/深度更新最多追加一次推理调用，复核与修订共享这一次预算；修订后最多一次 Jev 检查。五维争议合并，不逐维调用。仍有争议标注待作者核查，不继续循环。没有争议就交付，不强制额外推理认证。所有内部调用不另扣用户学分，但记录真实供应商用量与成本。

生成可流式显示，明确标为草稿/核查中。修订保留初稿和变更提示，不覆盖用户编辑；正式导出默认最终冻结版，检查中复制需提示未核查。终态区分检查完成、仍需作者核查、自动复核不可用，不承诺绝对准确。

## 5. 仅生成结果的五维雷达图

评价对象为 AI 生成的冻结摘要版本，不是上传论文；每次生成/深度更新独立评估。维度：报告完整性、方法描述充分性、结论与证据一致性、会议适配性、原文忠实度（幻觉风险）。完整性/方法要求按摘要篇幅和会议规则判断。

第五维检查事实忠实性，与第三维的推论夸大区分。显示未发现明确偏离、存在待核查内容、发现明确偏离；不能称准确率，不能认为原文本身已证实正确。雷达绘图数值只是固定有序等级的编码，统一方向、显示文字锚点，不给百分制、综合总分或面积排名。

无法判断/不适用不记零，不填补，不补齐多边形；未选择会议时该维不适用。风险项链接真实生成语句及原文范围，不捏造引用。Jev 初判；推理 LLM 只复核争议项，保留双方来源与分歧，不平均、不取最高；未解决项保持待核查。

版本绑定包括原文 hash、输出 hash、会议规则/量表版本、模型尝试及最终状态；迟到结果不得覆盖另一版本。用户手改不触发重新评估、不显示重新核查按钮；始终注明评估对应 AI 生成版本、不包含后续手动修改。历史评估随生成版本查看。

## 6. 两类图入口独立

### 数据统计图

数据输入 → 代码解析和字段校验 → Jev 根据字段、数据形态与研究目的推荐允许图型/模板 → 推理 LLM 在需要时规划复杂样式 → 用户确认 → Python 渲染。

沿用数据图设计的独立实现、11 类模板、12 个合成临床案例、单文件单工作表、最多四面板、无推断性统计计算、缺失值逐面板确认。免费方案阶段最多两次模型规划；加入 Jev 不将这个限制重置为每个 provider 两次，也不允许每次字段编辑触发调用。自然语言最终方案仍由推理 LLM 完成。成功图版本 1 学分，失败返还，已有格式下载免费。

### 科研示意图

仅 text-to-image 与 image-to-image，不由 Jev 将用户切换到数据图入口。Jev 从现有七大类中推荐类型，用户确认或修改后再推荐期刊视觉预设；两次存在依赖，不能假设同批问题读取另一答案。用户已有选择就跳过该选择的判断，不覆盖。

按已选图类型检查主体、布局、关系、风格、限制条件的充分性；并非所有图都要求数据关系，不虚构事实补齐 prompt。推理 LLM 生成最终提示词，用户选定的图像模型执行。Jev 不直接理解参考图，也不对成图作视觉正确性认证。期刊只是视觉预设，不声称满足其全部投稿规则。

### 重试与费用

Jev 只辅助处理需要语义判断的失败，给出建议重试、建议修改、不建议重试，用户确认后才发起新图像请求。鉴权、限流、超时等明确错误由代码处理；既有技术 fallback 有独立上限，不因 Jev 建议增加尝试次数。已知失败凭证不足时不得伪造失败原因。

无有效图片的失败任务净扣 0。用户确认重试作为新任务预留 2 学分，成功扣除、失败返还。同一任务技术 fallback 不重复收费。已有成功图片再生成是新任务，成功另扣 2。沿用服务端幂等和钱包事务，不只修改文案。

## 7. 独立盲审

点击盲审后自动执行预筛 → 推理 LLM 完整评审，不增加中途确认，总费 1 学分。LLM 同时读取原文与预筛，独立核查，不只审 Jev 标记内容。预筛故障时仍完成原评审。进度显示预筛中/评审中；此范围不默认给盲审报告增加摘要雷达图。

## 8. 降级、披露与发布

Jev 不可用：摘要交付 LLM 输出但注明复核不可用；盲审由 LLM 完整完成；图型/期刊保留用户选择，缺少必要选择请用户确认，不猜测。权限、余额、schema、安全校验不降级。不得把未执行/失败标成检查通过。

披露记录实际参与的 Jev 与推理模型、阶段、版本及有限修订，不凭请求别名推断实际模型；沿用平台与项目声明。区分用户学分和供应商成本，拒绝同意或 BYOK 不产生虚假 Jev 记录。

独立开关：adapter、基础分析、摘要 post-check/结果评估、盲审预筛、示意图判断、数据图推荐。先许可允许的公开论文与人工构造错误样本验证，再灰度摘要，再扩展盲审/两类图。不同子任务可并行实现，不同时默认上线。

验证覆盖中英文、研究类型、样本量错误、虚构结果、因果夸大、条件遗漏，调试/验收集分离。不读取会员论文或生产库作测试。上线要求重大错误漏检不增加、误报与分类/等级表现可解释、完整任务平均成本下降、首字与最终交付延迟分别报告且最终等待不明显恶化，以及权限/降级/计费/版本/披露测试全部通过。实际数值阈值和样本规模在验证协议中显式记录后再验收，不拿模型一致当正确性证据。

## 9. 执行边界

先审阅工作区已有未提交 Jev 代码，再基于现有实现做增量计划；不得覆盖另一项在进行的开发。子 agents 按清晰文件所有权分工，先共享契约，再并行，最后集成验证。没有生产部署、付费资源创建或真实论文外发授权；开发测试默认 mock/合成数据，真实 API 验证另行明确数据和预算。

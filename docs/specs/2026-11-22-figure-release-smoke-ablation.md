## 消融：数据图判别契约

- 假设：在相同字段摘要与固定的模板评分下，将新增的长度/内容评估移除，只保留旧版模板路由，候选解析应不变，而返回的摘要评估维度消失。
- 配置：Darwin arm64，Node v22.23.2，Vitest 4.1.10；同一组固定合成字段、目标及11个固定模板分数；新版另提供两个固定合成分数。旧 `buildDataFigureRoutingRequest`/`parseDataFigureRoutingResponse` 为基线，新 `buildDataFigureAssessmentRequest`/`parseDataFigureAssessmentResponse` 为完整组。执行 `npx --no-install vitest run backend/_jev/dataFigureAblation.test.ts`；不访问模型或数据库。
- 实测：基线11个问题、请求JSON 9,343 UTF-8字节、1个候选；完整组13个问题、10,703字节、同一个候选，另输出长度适切性0.85、内容充分性0.73。新增1,360字节是此固定输入的序列化差异，不是token、计费或端到端延迟测量。
- 结论：消融了新增摘要评分问题后，固定输入和合成回答下，模板解析结果相同但评分字段缺失。本实验不是对Jev模型的实际调用，不能得出准确率、分类质量、降本或提速结论。要评估这些指标，需要事先定义标注数据集、模型版本、真实用量与成本，并获得调用授权。

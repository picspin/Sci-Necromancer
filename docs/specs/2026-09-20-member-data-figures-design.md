本轮三类模板的实现边界（沿用已确认目录，不增加依赖或生产接口）：

1. 排名图输入标签、已有数值及可选分组；用户明确排序与 top-N，同分保持原顺序，记录省略数量。
2. 构成图首个变体接受互斥且穷尽的计数、每组明确分母；总计不符或缺类别则拒绝，不自动补零。
3. 用户选择堆叠计数或组内百分比；百分比只按已确认分母计算，不自动归一化任意比例。
4. 火山图输入已有 log2FC 与 P/adjusted P，明确阈值；不做差异分析、检验或校正。
5. P=0 必须声明可解释的显示下限并披露数量；正 P 保留数值，不能被统一截断。
6. 每类连接冻结 FigureSpec 与 PNG/PDF/SVG，校验原始文件 hash 和限定参数。
7. 合成数据验证已知坐标、分母、排序、阈值、失败输入、版本与重复导出；会员入口仍关闭。

`services/figure_worker/` 现支持九类基础模板的有界 CSV 校验及内存 PNG/PDF/SVG 导出：分组条形、散点、原始热力矩阵、数值趋势、点区间、森林图、排名棒棒糖、计数/百分比构成图、已有差异结果火山图。这不代表模板目录的所有变体已经完成：趋势当前仅接受每条序列严格递增的数值横轴，热力图只接受完整原始矩阵；区间由用户提供端点与类型，森林图还必须声明效应量和 CI 水平，不推算或合并统计结果。

排名 v1 接受最多 5,000 条已有分数与八个可选分组；同一数值单位，标签唯一，显示 top-N 上限为 24，全部输入行先校验。构成 v1 只接受整数计数和已提供的组内分母，最多十二组、八个共同类别；不接直接比例或全体分母，不把缺类别解释为零。火山 v1 接受最多 5,000 个唯一标识的已有 log2FC 与 P/adjusted P；阈值与纵轴语义明确，P=0 的显示下限不得高于阈值或任一正 P。负对数先在固定 28 位 Decimal 环境计算，再转换绘图数值，避免极小正 P 被浮点转换为零。原值与截断数量进入图件方案证据，不校正 P 值，也不自动生成研究结论。

`spec.py` 将 CSV 与明确确认的 `figure-spec-v1` 方案连接起来；校验文件 SHA-256、模板版本、列映射、单位和区间语义，拒绝额外脚本、路径、URL、原始数值或未实现的变换。创建布局和导出阶段均禁用外部 TeX。方案只是一道本地输入边界，不能替代会员授权、计费或执行隔离。

实验记录：假设是“已确认方案可忠实导出已有数据，而不由模型补数或执行代码”；本轮实测环境为 `macOS-27.0-arm64-arm-64bit`、Python 3.10.11、Matplotlib 3.10.9、锁定依赖与字体，不使用随机采样。结果为 66 项合成数据 Python 测试通过（上一轮 47 项），含九类端到端导出、数值位置、错误输入、重复导出哈希与外部 TeX 禁用回归。构成百分比的回归先复现环境精度改为三位时 `2/3` 从约 `66.66666666666666%` 变为 `66.7%`，改用精确可表示的整数计数执行固定浮点绘图换算后，该测试与普通环境一致；火山阈值比较同样不受 Decimal 精度舍入影响。另导出三种本轮合成预览检查布局；没有真实患者数据、供应商调用、性能或模型准确度提升的结论。JS/TS 回归 96 文件、586 测试，以及 lint/build 通过，仍有既有大 chunk/混合导入构建警告。CI job 执行锁定 Python 依赖与上述测试，不自动部署；同环境重复一致不承诺跨 OS/依赖版本字节相同。

接下来的未完成项：已约定图型变体与十二个合成临床案例、XLSX 和授权中文字体；以及会员上传、私有存储、持久任务/隔离 worker、成功版本扣分及失败退款、模型/Jev 规划和前端工作区。生产 worker 的平台、成本与区域仍待确认。入口继续显示“开发中”，本地模板测试通过不等于线上可用。

## 3. 三层产品结构

| 层次       | 建议位置                          | 职责                                                                   |
| ---------- | --------------------------------- | ---------------------------------------------------------------------- |
| 独立 Skill | skills/clinical-data-figures/     | 需求解释、图型选择、字段要求、统计边界、输出检查；由服务端固定版本加载 |

模板体系区分“原子图型”和“临床组合案例”：同一图型可服务多个学科，案例通过字段映射与最多四面板组合复用图型，不为每个疾病复制渲染代码。首版设计扩展为 11 个原子图型、12 个临床案例；全部为待独立实现的交付目标，不代表目前已有这些功能。

## 4. 用户界面与操作流程

IMAGE 板块增加“数据作图”入口，与现有图生图、文生图并列；内部使用独立 DataFigurePanel，避免扩大现有 useImageGeneration 状态机。

1. 未登录用户看到模板预览和注册/登录 CTA。已登录用户可启用数据作图能力。
2. 上传 CSV/XLSX 或加载合成示例；选择工作表，查看列类型、行数、缺失比例和异常值提示。
3. 用户确认研究单位、字段含义、单位、组别顺序、图型和允许的数据转换。
4. 左侧填写自然语言外观要求，右侧显示模板示例与字段预检；此阶段不调用 LLM，不扣学分。
5. 点击“生成图件 · 1 学分”，服务器冻结输入版本、允许的变换和所选会员模型，创建可恢复的异步任务。
6. 模型输出结构化方案；服务器验证后交给 Python 渲染。若必需信息不足，返回需要补充的字段并释放预留，不让模型自行填数。
7. 右侧展示图件、数据处理摘要、警告、版本历史、AI 使用声明和下载入口。
8. 自然语言修改创建新版本，展示费用后执行；旧版本不覆盖。每次可选择当前会员模型，运行中不能改变该任务模型。

全局若选中 BYOK，数据作图区明确显示“此功能使用会员文本模型”，使用独立会员模型选择，不静默改变全局 BYOK 设置。不将个人 API 密钥发送到会员服务端。

浏览器缩放、切换已有导出格式、下载、显示/隐藏辅助说明免费。首版没有免费服务端重新渲染接口：改变最终文件中的颜色、标签或布局通过新版本完成；防止将渲染调用伪装成免费预览。

输入缺失、服务不可用或余额不足时在调用模型之前提示。双击、刷新、离开页面不重复创建任务；重新登录同一账号可恢复尚未到期的任务。中英文文案与键盘操作完整覆盖。

## 5. 首版模板与数据契约

| 模板       | 输入                                   | 首版计算与约束                                                                          |
| ---------- | -------------------------------------- | --------------------------------------------------------------------------------------- |
| 分布图     | 数值列、可选分组列                     | 箱线＋散点；小提琴可选。明确四分位数算法、KDE 参数及样本量不足处理，不自动做检验        |
| 分组条形图 | 类别＋计数，或已汇总数值               | 原始计数/比例、明确选定的汇总；条形从零开始，不通过截轴夸大差异                         |
| 趋势图     | 时间/顺序、数值、分组                  | 原始趋势或明确选择的均值/中位数；禁止默认平滑/插值；重复受试者不当独立样本计算 CI       |
| 散点图     | 两列数值、可选分组                     | 原始观测展示；无拟合线、P 值或因果解释                                                  |
| 热力图     | 数值矩阵，或数值列集合                 | 原始矩阵、明确选择的标准化，或 Pearson/Spearman 描述性相关系数；不计算显著性            |
| 森林图     | 标签、效应量、CI 下限/上限、效应量类型 | 仅显示用户已有结果；明确 CI 水平。OR/RR/HR 正值和对数轴校验，不混合类型、不计算合并效应 |
| 火山图     | 标识、log2FC、P 或调整后 P             | 使用用户已有结果；明确阈值与纵轴含义，不运行差异分析/FDR 校正，不将 P=0 直接取对数      |

多面板只组合上述模板，最多四面板，共享同一个数据集版本，布局和配色一致；每个面板单独定义映射与变换。

上述七类是基础能力，另纳入四类：堆叠/百分比构成图、点区间图、雷达图、排名棒棒糖图。基础类型增加横向条形、累积计数与事件标注、已计算参数扫描、带数值注释的计数/评分热力图、已有二维嵌入坐标展示。完整 ID、输入约束与分期以模板目录为准；多指标分面是组合方式，不重复计为原子图型。

画廊按学科、研究任务、输入形态、图型筛选；先展示“所需数据/不执行的分析/合成示例”，再加载模板。自然语言只在匹配字段契约的模板内规划，不因输入“单细胞”“生存分析”等关键词承诺上游分析。

统计守则：

- 首版支持计数、比例、均值、中位数、样本 SD、分位数及描述性相关；算法版本与缺失值处理进入 manifest。
- 不根据 SD 自动生成 SE/CI；只有用户提供对应误差字段和类型才绘制误差线。CI 必须声明水平；无法识别含义则拒绝。
- 分母明确：比例按全体有效样本还是组内有效样本由用户选择；分母为零不生成有效百分比。
- 缺失值默认阻止受影响面板，允许用户明确选择完整案例剔除并记录剔除行数；不做隐式插补。相关性首版统一使用选定列的完整案例，不默认逐对删失。
- 同一受试者重复记录需明确标识；趋势可显示个人轨迹或显式汇总，不擅自推断配对设计。
- 不自动删除离群点。散点抽样只用于显示，固定随机种子并标明展示数量，统计摘要基于完整有效数据。
- 森林图验证 lower <= estimate <= upper；火山图校验 P 在 [0,1]，零值必须由用户提供可解释的显示下限并注明截断。
- 绘图文字中不自动添加“显著”“改善”等研究结论。

所有模板都提供最小合成输入、预期结果、错误示例及可运行演示；合成图明确标识为演示，不混入正式图件。

## 6. 输入与隐私

建议首版上限：每次一个文件、10 MiB、单工作表最多 50,000 行/100 列且最多 1,000,000 单元格；XLSX 解压后总内容不超过 50 MiB。前后端都校验，服务器为最终边界。

CSV 使用明确 UTF-8 编码；不猜测无法解析的编码。XLSX 拒绝宏、外部链接及公式单元格，提示导出为值后上传；不执行公式、不自动抓取 URL、不加载 pickle。拒绝重复/空列名、非有限数字和不一致的数值转换；展示问题位置供用户修正。

数据进入临时工作区前提醒用户去标识化。默认不向 LLM 提供原始行、患者标识、自由文本单元格或稀有分类值；只提供经过用户确认的字段别名、类型、必要的数据规模及模板选项。字段与组别使用内部 ID，原始标签只在受控 renderer 中应用。自然语言输入也提示不要含患者信息。

文件私有存储按用户隔离，原始文件、规范化数据、绘图方案、图件与复现包均设置 24 小时生命周期。用户可提前删除；清理作业失败必须报警并重试，不能只删除数据库指针。财务流水保留最小元数据，不包含文件名、原始标签、自由文本指令或数据摘要。

首次发布需在隐私说明中明确数据用途、实际部署区域、模型提供方、24 小时保留策略和删除途径。选定执行与存储服务后再填写真实区域，不推定“脱敏即绝对匿名”。

## 7. 执行架构

推荐结构：Vue 工作区 → Vercel 认证/任务 API → Supabase 任务记录与学分事务 → 独立 Python worker → 私有产物存储。

- Vercel API 不同步等待整个渲染过程；创建成功返回 202 与 taskId，前端轮询状态。
- 任务创建与学分预留在一个数据库事务中提交；任务表作为持久队列。worker 使用租约领取任务，数据库重启或实例退出后可恢复。
- LLM 仅返回版本化 FigureSpec JSON，不返回待执行 Python。FigureSpec 允许字段映射、模板、布局与白名单样式；严禁脚本、表达式、任意文件路径和远端资源 URL。
- 编排进程调用会员文本模型；renderer 子进程/容器不持有模型密钥、Supabase service-role 或用户会话。
- 每任务独立工作目录，非 root、只读程序文件、网络禁用、固定依赖、内存/CPU/执行超时限制。纯 JSON 规划不替代运行隔离。
- 数据下载和上传由受信任编排层执行，renderer 只访问本次输入及输出目录。关闭外部 TeX 执行，默认使用 Matplotlib 内建数学文本和已授权字体。
- 初始限制：每用户一个运行任务，任务总时限 180 秒，其中单次模型最长 60 秒、渲染最长 30 秒；最多一次结构化输出修复调用，全部共用同一计费任务和总时限。
- 全部任务具备服务端频率/并发限制；初始模型任务每会员每小时最多 20 次尝试，失败也计尝试次数，不计学分。上传与预检另设请求和容量限额。
- 不以进程内任务表或前端计时器实现队列、锁、计费或过期。

本地开发提供容器运行方式；生产 worker 的承载平台在部署阶段根据现有资源选择。实现依赖的是上述隔离/持久队列契约，而非某厂商 SDK。选定平台、资源配额、成本和区域前，生产能力开关保持关闭。

## 8. 图件、任务与接口

核心对象：DataSet（owner、输入 hash、解析器版本、expiresAt）、FigureVersion（数据版本、模板版本、FigureSpec、父版本）、FigureTask（身份、模型快照、租约、计费状态）、Artifact（私有路径、媒体类型、大小、hash、expiresAt）。

候选 API（具体文件布局在实现计划中确定）：

- GET /api/figures/templates：静态模板 manifest 与合成预览，不返回执行指令或会员数据。
- POST /api/member/figures/datasets：验证身份与配额，申请仅能写入指定对象的短期上传授权。
- POST /api/member/figures/datasets/:id/validate：核验实际对象大小/类型，异步解析，返回受控字段信息。
- POST /api/member/figures/tasks：输入 datasetId、templateId、字段映射、明确的变换、用户指令、memberModel 和幂等键；不接收客户端价格、ownerId 或脚本。
- GET /api/member/figures/tasks/:id：只返回所属会员的状态、警告及已结算版本；不返回内部密钥/日志。
- POST /api/member/figures/tasks/:id/cancel：发出取消请求，服务器裁决是否已经完成。
- GET /api/member/figures/artifacts/:id：再次核验所有权，返回短时下载授权。SVG 以图片或下载方式呈现，不内联执行。
- DELETE /api/member/figures/datasets/:id：取消未完成任务并删除相关文件；财务记录不随文件删除。

上传完成后才允许解析和任务创建；同一用户也不能引用已过期、删除中或不匹配的数据 hash。短时下载 URL 视为 bearer 凭证，不记录到日志或作为永久公开链接。

## 9. 学分与故障一致性

新增 data_figure_generation、data_figure_revision 任务类型，不伪装成 image_generation 或 blind_review。两者成功均结算 1 学分；不是“每个模型调用”收费，多面板图及其多格式导出属于一次交付。

沿用现有预扣/失败返还的 wallet 模式：创建时原子预留/预扣 1，UI 明示“处理中预留 1 学分”；成功确认扣费，失败或接受取消后自动返还。若采用独立冻结余额实现，必须让所有旧消费路径共同扣除冻结额，不能形成可重复支出的余额。

必须保持以下不变量：

1. (userId, idempotencyKey) 唯一；同键同参数返回同任务，异参数冲突，重复请求不重复调用或扣费。完成或失败的同键请求都不隐式创建新任务。
2. 状态为 queued → planning → rendering → validating → completed；失败/取消进入返还流程。所有转换验证状态及租约版本，旧 worker 不能提交迟到结果。
3. PNG、PDF、SVG、脚本及 manifest 全部通过验证并存入私有存储后，才在单个数据库事务内确认扣费并发布产物清单。模型仅返回文字不算成功。
4. 上传完成但结算失败：产物不可下载；重试结算或恢复任务，不重复运行已验证的渲染。最终失败释放预留并清理孤立产物。
5. 已完成但浏览器断线：任务可查询，仍仅收取一次，不因响应丢失退款重跑。
6. 取消与完成竞争通过数据库原子比较更新裁决；完成先提交则保留产物及扣费，取消先提交则迟到结果丢弃并返还。
7. worker 崩溃、租约超时、数据库不可用均由恢复进程协调；完成资金状态前不将任务显示为“已退款”。返还失败持久标记并报警。
8. 内部修复和重试共用 reservation；超出预算失败返还。用户明确发起新的修改版本才产生新预留。

学分明细标注“数据作图/修改”、taskId、figureVersionId、请求模型/实际模型、费用和退款状态。模型执行记录追加保存每次尝试及角色；图件披露包含对当前版本有贡献的父版本模型记录，不凭前端选项编造实际使用模型。

## 10. 可复现与输出校验

交付 PNG 预览、PDF/SVG 矢量图、独立生成的 Python 脚本、FigureSpec、依赖锁定信息、数据 hash、模板/运行时版本、随机种子、描述性计算方法、剔除计数及 AI 使用说明。

复现包默认不自动包含患者级数据；脚本要求用户提供原始输入并验证 hash，记录工作表与字段映射。选择将数据加入本地下载包时明确提示隐私影响；不把数据放进公开画廊。24 小时过期前提示下载。

所有格式对应同一冻结方案与输入。校验包括数值有效性、画布/面板数量、预期图元、可解码 PNG、PDF/SVG 格式、文件大小、标签溢出与字体可用性。无法消除的警告应交付前展示；硬错误不能结算。

图件遵循用户明确选择的尺寸和字号；样式不修改数据、阈值或统计方法。临床图默认可区分的配色与线型，组别映射跨版本稳定。期刊风格标记为视觉预设，不承诺自动满足某期刊当前投稿规则。

2026-10-01：九类本地基础模板已接入 Lancet/Nature/Cell/NEJM-inspired 独立风格注册表与冻结版本；见[风格增量与回归记录](./2026-10-01-data-figure-journal-styles.md)。尚未接通会员任务或前端选择器，不能以重部署代替后续工作。

AI 使用说明区分文本模型负责的需求解释/样式规划与 Python 负责的数据计算/渲染，包含 www.rad-sci.org、picspin/Sci-Necromancer、实际模型、操作和日期；作者仍负责数据与科学解释。

# 分布与雷达基础模板

## 实现草案（沿用已确认目录）

1. 输入仍为有界 CSV 与已冻结 FigureSpec，不新增服务、依赖或生产入口。
2. 分布首个变体为箱线＋全部观测散点；最多 5,000 行、八组，缺失拒绝，源顺序分组。
3. 分位数固定 H&F type 7 线性插值；箱须采用 1.5 IQR 范围内的观测极值，不删除离群值。
4. 单值、常数组仍显示全部观测并披露；横向错位仅用于可见性，固定规则，无随机抽样。
5. 本增量不运行 KDE、检验或拟合，直方图/小提琴等其他变体仍待实现，不能通过参数绕过。
6. 雷达接受完整 method×metric 长表和每轴单位/上下界/方向；最多八轴、四方法，缺失/重复/越界拒绝。
7. 显式 min-max 归一化，lower-is-better 反向；原值不改，不计算面积评分或排名。
8. 雷达交付三种图件及独立原值 CSV 表（含轴元数据与归一化值），避免把不同单位当作原始同尺度指标。
9. 两类复用期刊外观白名单与导出哈希；明确记录统计方法、全部原值和方案参数。
10. 本地合成输入验证，会员上传/任务/计费仍不接通，未经授权不执行部署。

方法依据：[NumPy quantile 的 H&F type 7 定义](https://numpy.org/doc/stable/reference/generated/numpy.quantile.html)、[Matplotlib bxp 的预计算箱线契约](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.bxp.html)。独立实现描述性计算，不复用参考项目代码或数据。

## 已实现边界

- `distribution-box-scatter-v1`：所有行先校验；数值字符串最多 128 字符且可转换为有限绘图数值。分位数与 1.5 IQR 比较使用标准库 Fraction 精确运算，最终转 binary64，不受调用方 Decimal 精度影响。单值/常数组照常显示并披露，散点固定源顺序横向错位，不承载数值含义；图上显示每组 n。不能绘制的数值跨度失败，不调整原值使其“看起来正常”。
- `radar-explicit-axes-v1`：3–8 轴、1–4 方法；32 个单元格以内完整长表。轴名最多 48 字符、单位 24 字符；每轴显式 `lower < upper` 和 `higher`/`lower` 方向，用户显式决定轴顺序。根 `units` 为 `{}`，单位位于逐轴配置。原始表同一指标只有一个单位与范围，不猜测或合并不同指标。
- 标准化：higher 为 `(value-lower)/(upper-lower)`，lower 为 `(upper-value)/(upper-lower)`，精确有理数换算后转 binary64。外圈代表声明方向上的较好值，但不计算面积评分、加权分数或优劣结论；不可表示的非零归一化值拒绝，不裁剪成 0。
- `RenderedFigure.artifacts` 仍是 PNG/PDF/SVG；雷达另带 `data_table` CSV artifact 与独立 SHA-256，包含原值、单位、范围、方向和实际绘制的 normalized 值。其他模板该字段为 None。源数据和轴配置进入 FigureSpec hash；期刊外观改变不会改变 CSV 原值附件。
- CSV 的 method/metric/unit 文本若以 `= + - @` 开头，添加前导单引号，并在 `escaped_text_fields` 标记列名；复核时可按标记移除恰一个单引号恢复标签。数值字段使用解析后的 Decimal 字符串，保留数值与负号；这不是执行 CSV 或公式的入口。
- 图件说明、不支持的变体、数据哈希与模板版本均明确；仍不提供前端选择器、公开上传或会员任务。

## 合成验证记录

假设：缺少的两类基础图能在固定输入与算法下忠实展示数据；外观预设不改变科学编码。

配置：macOS 27.0 arm64 / Python 3.10.11 / Matplotlib 3.10.9，既有 uv.lock，确定性合成输入，无随机采样、模型请求、患者数据或付费动作。

结果：87 项 Python 测试通过（基线 71 项，分布切片 77 项）；十一模板 × 四期刊风格的 44 个组合校验不变的科学几何及多格式导出。已知分布 `[1,2,3,4,100]` 得到 Q1=2、中位数=3、Q3=4、箱须 1–4，原始 100 仍显示；样本 `[1,3]` 得到 Q1=1.5/中位数=2/Q3=2.5。单值、常数、高精度近邻、极端不可绘制数值都有回归。雷达已知输入 0.75 ratio/25 seconds/-2 mm 在明确范围和方向下为 0.75/0.75/0.7，原值附件逐行一致；覆盖缺轴、重复、越界、四方法八轴上限、下溢拒绝、公式标签转义和版本/hash变化。重复导出一致。

JS/TS：96 文件/586 测试、lint、build 通过；保留既有动态/静态导入与大 chunk 警告。人工查看 Lancet-inspired 合成分布图、Nature-inspired 合成雷达图，修正多行雷达标签与圆边重叠；测试增加向外对齐断言。这不是任意长标签的全面溢出检测或跨系统字节一致性承诺。

结论：十一类首个基础变体已覆盖，完整模板变体、十二例多面板画廊和会员交付仍未完成。没有性能/科研准确度提升实验，不能据此声称降本或提高模型准确率。

Ablation Pass：沿用现有校验/风格/导出入口；描述性计算由两个实际模板调用并被数值测试，不添加未来统计插件、任意代码或新依赖。原值附件解决当前雷达跨单位核对需求，不改变旧模板的三格式结构。

部署影响：Supabase 无迁移；Vercel 无需部署；Cloudflare Worker 无需重建/部署；无环境变量或生产开关变化。未执行生产操作，无本增量的生产发布顺序或付费烟测需求；CI/合并不启用会员入口。复现命令与完整上线清单仍见 [Deployment Runbook](../DEPLOYMENT_RUNBOOK.md)。

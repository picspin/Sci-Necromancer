# 本地多面板与放射影像验证案例

日期：2026-10-06。状态：本地增量已实现并验证；不启用会员数据图，未 push/部署。

## 实现草稿

1. 输入是一份有界 CSV 与独立版本的多面板 JSON，绑定完整源文件 SHA-256。
2. 每面板明确模板版本、字段映射、单位、标题及 record_type 精确等值选择。
3. 先支持 grouped-bar、dot-interval、heatmap；其他组合明确拒绝，不伪装支持十一类。
4. 同一源数据允许多面板复用；每个面板非空，所有源行至少进入一个面板，未覆盖行直接拒绝。
5. 将已有轴内绘制逻辑用于单图和组合图，旧单图方案/布局/导出保持不变；不合并不同单位的轴。
6. 两至四个面板共用白名单风格及一套 PNG/PDF/SVG 导出、冻结方案与依赖证据。
7. 首例为独立合成的放射影像模型验证：条形、作者提供的点区间、原始矩阵；不计算 AUC 或 CI。
8. 不新增依赖、模型调用、文件上传、生产接口、私有存储、数据库任务或计费；后续部署另行确认。

## 验收计划

- 重构前后比较旧模板各风格的三格式哈希，并运行现有全部 Python 回归。
- 检查明确值、区间端点、矩阵、两个到四个面板、色标不计面板、方案和输入 hash。
- 缺失值、空选择、未覆盖记录、非法映射/额外字段/版本/脚本/路径均拒绝，不输出局部成功图。
- 检查所有风格保持数据几何不变、重复导出、字体和画布边界；实际查看合成预览。
- 运行 JS/TS test、lint、build；完成后记录实际环境、结果、限制与删减检查。

## 实际验证记录

- 假设：已冻结的多面板方案能复用三个现有模板、忠实展示给定数值与区间，并保留完整源数据证据；不破坏旧单图行为。
- 配置：macOS-27.0-arm64-arm-64bit，Python 3.10.11、Matplotlib 3.10.9、既有 uv.lock/DejaVu Sans。八条固定的独立合成演示记录，不随机生成或抽样；不是研究结果或有效置信区间。
- 基线：修改前 100 项 Python 测试通过；旧 grouped-bar/dot-interval/heatmap × 五风格 × 三格式共 45 个实际导出 SHA-256 留作对照。
- 结果：115 项 Python 测试通过；45 个旧单图导出哈希在结构重构后及最终增量后均与基线一致。96 文件、586 项 JS/TS 测试以及 lint/build 通过；既有混合静态/动态导入和大 chunk 警告仍在。
- 新回归：两至四面板、五风格、数据几何不变、重复三格式导出及 PNG 解码；源行复用/全行覆盖/原始错误行号、冻结方案、缺失/重复/未覆盖/额外字段拒绝、字体/画布边界、组名不能在多个条形面板中换色、极小或溢出坐标拒绝，以及零和小而可绘制的常数保留。
- 数值反例：全体 AUC 数值为 1e-320 时，未门控的组合原型出现 Matplotlib 纵轴约 (-0.05, 0.05)；1e-300 常数热力色标同样被扩到约 (-0.1, 0.1)。组合入口现在核对请求与实际范围并拒绝此类失真，不用任意固定阈值截断。1e308 区间导致绘图库范围计算错误也拒绝；不声称修复了其他旧单图的全部极端数值问题。
- 人工验收：实际生成并查看 NEJM-inspired 三面板 PNG，图例置于条形数据区上方；同时生成 PDF/SVG 与 manifest。源 hash 为 `666f0189b34921aed2c0f5f7e5a7302e64873a2115d6a9799a1e23f5efbc3e4e`。测试断言 AUC 原值 [0.72, 0.78, 0.74, 0.80]、首个区间 [0.65, 0.79]、Dice 矩阵 [[0.65, 0.73], [0.68, 0.76]]，没有从模型或代码估计这些合成值。
- 结论：该有界本地路径和首例满足本轮验收；不推断临床有效性、AI 准确度提升、性能改善或跨平台字节一致。

## 边界与删减检查

- 仅 grouped-bar、dot-interval、heatmap 可参与组合，固定两列、最多四面板；不是通用脚本执行器或所有十一种模板的组合引擎。
- 同一输入可复用，但任意源行未覆盖则整体失败；无跨表关联、自动补值、自动筛选/归一化/统计推断。
- 样式预设不是期刊合规认证。现在检查整体画布、面板含色标/图例的包围框及标题/页脚碰撞；不保证任意轴内相邻标签或极限标签都互不重叠。未知字形明确拒绝，中文授权字体仍待实现。
- 首例只有本地仓库依赖的演示，不是公开网站画廊、独立下载复现包或会员上线。其余十一例、未完成图型变体、XLSX、隔离/持久任务/私有文件/钱包/Jev/LLM/前端仍待做。
- Ablation：三个轴内绘制函数分别被旧单图与组合调用；Panel/MultipanelPlan 绑定经校验的数据、冻结方案和行证据；没有增加通用插件、任意布局配置、预留服务层、依赖或未使用的模型参数。仅当前三个允许模板的逻辑，没有未来模板空壳。

日期：2026-11-01。基线为本地分支 `codex/data-figures-mainline` 的 `eaa11ad`；不是线上版本，也不代表这些提交已进入 PR #18。用户已确认本地回执方案；本计划不是生产发布或付费调用授权。

已完成：11类基础模板、5种期刊 inspired 风格、部分多面板、同源 Pyodide 工作区、严格 FigureSpec 规划契约（mock）、Jev 多候选建议及 v1 策略/v2 数据契约兼容修复。上一轮实际验证为705项JS/TS、120项Python测试；本次仅制定计划，没有重跑这些测试。

尚未闭环：真实会员规划请求、数据图专用版本/任务、成功结算、免费原图授权与工作区集成。生产入口仍受 DEV 硬门控，不能仅改开关或文案移除“开发中”。原有图像生成费用不受本计划修改；本数据图流程按既定规则每个成功生成/修改版本1学分，下载额外0学分。

完整范围还包括剩余临床案例、案例画廊、更多已规划多面板组合、XLSX、中文字体与安全/上线验证。首次真实会员闭环不等于这些全部完成；KM、ROC等尚无统计输入契约的图型仍在独立 backlog，不能用现有模板冒充实现。

## 实施前的模块设计草案（已确认本地回执边界）

1. 输入：已登录会员确认的图型、字段摘要/单位、期刊风格、目标、必要统计参数及本次选定会员模型；原始 CSV/患者行不发送给后端或模型。
2. 输出：服务端严格校验的映射草案、需要补齐的参数，或可确认的版本草案；本地可信模板完成渲染，禁止执行模型生成的 Python。
3. 边界：复用现有会员鉴权、模型映射和纯规划契约；新增数据图专用任务/版本记录，不向会议文本版本表伪填 conference、draft_text 等字段。
4. 模型：每次请求锁定所选模型；记录真实 provider/model、请求模型及模板/风格版本。没有实际调用就不填写“实际模型”。Jev 只建议，用户确认后才能进入规划。
5. 数据：CSV和原图字节留在浏览器；版本绑定所需数据/规格摘要将是新增服务端元数据，须在确认界面明确列出，不发送给模型。别名和目标等自填文本仍需用户去标识化。
6. 生命周期：待确认元数据→预留余额→规划→用户确认冻结规格→本地渲染→完成回执→结算。缺项、拒绝草案、取消、失败或过期均不形成成功收费；具体状态/RPC在第一切片冻结。
7. 财务：成功版本只结算1次；预留不是最终消费，失败/取消/过期释放。必须和现有文本、生图及其他扣费共享余额锁与可用余额规则，不能新增一个不约束其他消费的“独立预留”。
8. 导出：服务器核验身份、版本所有权和已结算状态；原图仍由本地 Worker 导出。余额为0仍可下载本人已付费版本。此授权不是DRM或渲染真实性证明，不阻止用户自行提取或重绘。

## 必须先确认的信任边界

浏览器完成回执可以被修改；数据哈希、图片哈希或 manifest 均不能证明客户端真正渲染成功。服务器只能保证任务归属、余额和结算幂等，不能在不接触产物的前提下证明本地执行。

推荐接受本地回执：维持数据主权，以每人单个活动任务、包含失败的尝试限流、短期预留、幂等结算与过期回收控制资源滥用。历史设计中的20次/小时先作为待验证阈值，不在本计划里悄悄改成无限重试。不能宣传“已防伪”或把浏览器回执当作可信钱包证据。

另一方案是服务端接收并验证产物，但这需要重新确认上传内容、隐私、存储、清理和成本，不能作为当前计划的隐含实现。

**当前状态：用户已确认接受本地回执方案。已实施第一步本地数据库契约，验证及未完项见[钱包预留记录](./2026-11-01-data-figure-wallet.md)；没有开启生产入口或调用真实会员模型。**

## 分步实施与验收

每个切片保持可独立回退，优先3–5个实现/测试文件；超过时先继续拆分。结构提取与行为变化分开提交。以下均先本地或隔离测试，不调用生产钱包或真实付费模型。

### 1. 钱包预留与数据图版本契约

- 前置：确认上述信任边界；逐项核对当前所有余额消费路径。
- 产出：新增向后兼容迁移草案与数据库测试，确定独立数据图版本字段、状态、过期和所有权规则；不复用会议文本记录。
- 验收：实际隔离PostgreSQL执行迁移；相同幂等键不重复预留；余额不足拒绝；文本/图像与数据图并发不得超支；取消/过期只释放一次；失败不得记成功消费。不能用SQL文本匹配或 dry-run 替代数据库执行。
- 门槛：若隔离数据库不可运行，明确标记未验证，不能称迁移已验收或应用到远端。

### 2. 服务端任务接口（先模拟供应商）

- 前置：步骤1的状态和数据库契约冻结。
- 产出：鉴权后的规划、状态、取消、完成接口；按实际Vercel入口布局选择接入点，先用模拟供应商，不盲目增加函数入口或依赖。
- 验收：跨用户访问拒绝、严格大小/字段白名单、失败计入限流、每人单任务、超时回收、迟到结果不覆盖新版本；完成与取消竞态只产生一种财务结果。

### 3. 真实会员文本供应商适配

- 前置：步骤2通过；沿用现有MGA适配和严格规划解析器。
- 产出：支持 DeepSeek V4.1 Flash / GPT-5.6 Terra，同价；模型锁定及实际供应商披露。功能默认关闭。
- 验收：mock transport验证真实请求形状、模型映射、畸形/缺项响应、上游失败及退款/释放；不向模型发送CSV或本地数据哈希；不自动修复JSON或补造统计参数。
- 边界：真实付费调用需要另外明确授权，不以mock通过声称上游质量或可用性已验证。

### 4. 工作区真实闭环

- 前置：步骤2、3接口稳定。
- 产出：两次明确确认→规划→冻结→真实本地渲染→完成/结算；取消、刷新、断线恢复和失败提示。
- 验收：区分“登录可访问”与“正余额可发起”；扣最后1学分后不清空数据/预览，已付费版本仍可导出；退出登录清理内存。切换文件、目标、模型或任务后，旧响应不能套到新数据。
- 用合成数据和模拟会员服务测试11类基础图，不冒用真实账号，不扣线上学分。

### 5. 免费原图授权与历史记录

- 前置：成功版本和所有权能由服务器读取，完成状态不可重复结算。
- 产出：统一官方PNG/PDF/SVG/复现包导出授权；本地Worker返回对应版本产物。预览保留 `sci-necromancer` 隐密标记；授权原图不嵌入此标记。记录生成/修改的1学分用途和实际模型，下载额外0学分。
- 验收：他人/未结算版本拒绝；余额0的本人成功版本允许；重复下载不扣费；全部格式使用同一权限检查；检查实际像素和DPI元数据，而非只改文件名或标签。浏览器数据已丢失时明确告知需重新提供匹配数据，不承诺服务器保存原图。
- 限制：可复制的浏览器代码和本地产物不具备不可绕过的去水印保护；官方授权只约束站内按钮与服务端接口。

### 6. 补齐案例与易用性

- 对照既有模板目录逐项列出12个临床案例的实际状态、必要字段和统计边界；先完成可用模板能支持的组合，再补必要的多面板能力，不新增任意布局执行器。
- 画廊只使用自建合成数据；固定种子和版本，记录输入、实际结果与边界；不复制受限上游数据或将期刊 inspired 风格称为官方认证。
- XLSX解析或中文字体若需新增生产依赖/资源，先给出版本、许可证、体积和隐私影响，取得确认再接入。

### 7. 上线审核与受控开放

- 合成E2E覆盖取消/超时/重复提交/并发/余额耗尽/授权/所有图型和风格；全量JS/TS、Python、类型检查、构建及同源资源完整性检查。
- 独立处理既有依赖风险；上一轮审计仍报告14 high、1 critical、4 moderate，本轮没有重新审计或修复，不能据测试通过跳过安全审核。
- 国内无代理访问、首次包加载、低内存设备和中文字体均须实际验证；“部署在Cloudflare”不是国内可达性的证明。
- 明确发布提交、迁移清单、后端/前端变量、回滚与受控测试账户后，再申请生产发布及付费烟测授权。

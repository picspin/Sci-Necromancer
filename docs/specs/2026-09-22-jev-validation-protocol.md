# Jev 发布验证协议

状态：待执行。该协议不声称模型准确性已经提升，不构成真实 API 调用或私有数据外发授权。

## 比较对象

基线为发布时现有会员流程，新流程固定 TypeSafe 模型、问题集、会议规则、推理模型及代码版本。对相同样本/用户操作比较完整任务，不只比较分类调用。GLM-5.2 和 GPT-5.6 Luna 分别记录，不混算掩盖差异。

## 数据与标签

仅使用授权范围允许的公开论文节选及独立合成样本，逐份登记 URL、许可、取得日期、内容 hash。无明确许可的材料不进入仓库。禁止生产库、会员论文、患者身份信息及凭证。样本集分调试集和冻结验收集，关联同一篇论文的变体必须在同一划分，避免原稿与篡改稿跨集泄漏。

每例标注语言、研究类型、会议、原文、生成候选、事实错误/无依据补充/结论夸大/关键遗漏、原文证据位置，以及各维度的可判断性。包含无错误对照、未知/不适用、否定句、数值单位、重复测量及不完整报告。人工标签由有能力解释依据的审核者完成；分歧保留，不用任一模型结果代替真值。

上线前冻结样本量、各语言/研究类型配额、误报容忍范围、延迟容忍范围及置信区间方法，由维护者确认；未冻结时不得以选择性的“若干成功案例”宣称通过。小样本零漏检不代表实际漏检率为零。

## 必须报告

| 目标             | 统计口径                                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| 重大事实错误漏检 | 人工确认的重大错误中未被指出的比例，基线与新流程成对比较；分别报告子组及不确定区间                |
| 误报             | 无问题句子/样本被标成错误的比例；待核查单列，不混作真阳性                                         |
| 分类与等级       | 对标注标签的一致性、混淆矩阵、无法判断率和覆盖率；评分不是百分准确率                              |
| 成本             | 原始生成、全部 Jev、追加推理、修订后检查、失败/超时消耗的真实用量与费用；缺失 cost 标未知，不填零 |
| 时间             | 首字与最终冻结交付分别统计中位数及尾延迟；缓存命中和未命中分开                                    |
| 用户费用         | 成功/失败/同任务 fallback/新重试的学分净变化；供应商费用不等于会员学分                            |

## 工程门禁

1. BYOK、未登录、未同意、余额为零发起新分析均不触发 TypeSafe；用户已拒绝同意仍能走原会员流程。
2. 真 PostgreSQL 中并行同键请求最多一个供应商调用许可；并行不同键严格受 3/分钟与 30/滚动日限制。失败退每日容量但不清除分钟压力。
3. 同意撤销、任务超时、租约过期、服务重启与迟到结果不发布错误版本；缓存跨账号不可取。
4. paid reservation 后余额为零不阻断内部检查；失败图片净扣0，新成功重试扣2，同任务 fallback 不重复扣。
5. 响应空 answers、漏题、错类型、无效概率、错误模型元数据均视为协议错误。没有核查结果不能标检查完成。
6. 生成/深度更新最多一次追加推理、一次修订后检查；无争议不追加推理；失败路径不会隐式转用另一 Jev 提供方。
7. 雷达只绑定冻结生成版本，未知维度不补零、不补多边形；手改文字不沿用成当前评估。
8. 两类图入口不自动互转；用户已选图类型/期刊不覆盖；Jev 重试建议不会自动发图像请求。

生产开关默认关闭。数据库静态 SQL 检查、mock 测试与构建成功均有价值，但不能替代以上真实事务与真实模型质量验证。

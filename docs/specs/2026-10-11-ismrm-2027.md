# ISMRM 2027 年度规则更新

核对日期：2026-10-11；规则版本：`ISMRM-2027-2026-10-11`。

## 设计边界

1. 输入仍是原稿、模型分类候选、作者选择，以及已有摘要草稿。
2. 输出是当前年度的分类/关键词、类型选择、生成提示和盲审规则。
3. 在现有 `ismrmData.ts` 中维护共享年度规则，不新增服务或生产依赖。
4. 生成、校验、服务端盲审共用规则；服务端不通过浏览器相对路径读取指南。
5. Vue 分析面板提供完整官方目录，作者可修正或补齐模型推荐。
6. 历史 Registered 类型保持可读取，但不能作为已验证的 2027 新投稿类型生成。
7. 计费、会员/BYOK 路由、Jev 服务、模型选择和数据统计图的上线状态不变。
8. 不自动提交 ECHO、不确认作者资格、不保证录用，不代替作者伦理与事实复核。

## 官方依据与主要变化

- [2027 Call](https://www.ismrm.org/27m/call/)：投稿窗口为 2026-10-01 至 2026-10-28；会议为 2027-05-08 至 2027-05-13，温哥华。未推断截止具体时刻或时区。
- [Standard](https://www.ismrm.org/27m/call/standard/)：标题≤125字符、正文≤750词（References 不计）、Impact≤40词、Synopsis≤100词。原平台较短正文和较长 Synopsis 的旧规则已替换。推荐正文结构为 Introduction / Methods / Results / Discussion / Conclusion，官方允许有合理理由时调整，不把推荐结构说成绝对要求。
- [Clinical Practice](https://www.ismrm.org/27m/call/clinical/)：Clinical Presentation and Assessment / Diagnosis and Treatment / Significance / 至少3个 Key Points；Synopsis 是非结构化临床叙述。生成时改写早期的研究式 Synopsis，而非原样复制。
- [MD-PhD Tandem](https://www.ismrm.org/27m/call/tandem/)：新增临床专家与技术专家联合第一作者/报告人类型，沿用 Standard 研究格式；作者自行确认资格与共同报告安排。
- [独立 ISMRT 通道](https://www.ismrm.org/27m/call/ismrt/)：面向技师/放射技师，要求 CV，并区分临床实践和研究；不是根据稿件器官分类就自动推断资格。
- Call 中的 Deep Dive into New Dimensions 是 Standard 的可选展示意向，不是新摘要类型或保证的展示形式。平台提示作者在 ECHO 选择，尚未增加上传/提交该字段的自动化。
- [分类 PDF](https://www.ismrm.org/27/docs/27m_categories_and_keywords.pdf)：导入13个类别、184个编码子分类和96个独立 General keywords。关键词列不是同一行子分类的绑定关键词。主、次类别可以相同，但子分类必须不同。
- [ECHO 指南](https://www.ismrm.org/27m/call/submission-guide/)允许最多5个关键词；Call 要求选择一个 General keyword（可自定义）。界面允许1–5项、官方下拉/自定义、显式撤销；超过5项的模型建议不静默截断，作者需删减。

下载核验的分类 PDF SHA-256：`7d37e0de5f44392553d4727f7717cea9b852e8527d9680e30733427023276e80`。本地公开 Markdown 与运行时分类表保留编码，后续以官方修订为准。

最多5张评审图、每张图注≤500字符，另有不参加评审的无图注手机可读 Preview Figure。此处更新了规则提示，并未新增图件上传、尺寸检测或 ECHO 导出能力。

资助、代码、数据和辅助链接按官方要求仅置于独立 Acknowledgements，不向评审提供。平台/实际模型的 AI 使用声明分离于评审正文是本平台的匿名性处理建议，并非声称官方新增了特定平台引用义务；作者核对提交位置。创意模式不再要求虚构完成研究的结果，缺失事实标记 `[author to verify]`。

## 不确定项与兼容

当前2027官方类型没有列出 Registered Abstract：保留历史类型和旧文档，但不把它提供给2027新生成；这不等同于宣称官方已永久取消该类型。部分网页仍残留2026 dues/年份及 ISMRT 旧文案，Call 的撤稿日期也相互冲突；未复制这些内容为已确认的新规则。最终提交前应查 ECHO 和主办方确认。

浏览器指南缓存加入年度版本检查，未过期的2026缓存也不会复用。旧模型分类不匹配2027目录时，作者可用主/次下拉手动恢复。Jev 仅分类时允许留空 Impact/Synopsis 草稿，由后续写作模型根据源文生成；非 Jev 路径仍校验必要草稿和字数。

2026-10-29 提交复查补齐会员 `/api/jev` 的服务端候选：与前端共用184个子分类、96个关键词，不继续发送旧年度9项分类。仅 ISMRM 的候选数量上限随官方目录确定，请求序列化字节上限为192,000；其他会议仍为64项/120,000字节。源文字符、标签、响应类型、同意、限流、租约、幂等与一次分析的预留/结算流程保留。完整目录产生285个独立判别问题，不把单次 HTTP 请求等同于固定供应商成本；真实处理能力、延迟和用量需在授权烟测中核验，未实测，不自动启用原本关闭的 Jev 开关。超过总请求预算的长稿仍会在供应商请求前拒绝。

- `npm test -- --run`：原工作区98个测试文件、602项测试通过；2026-10-29 独立主分支增量另补2项会员目录/候选限额回归，共604项，包含普通 Node 加载服务端产物的导入契约测试。
- `npm run lint`：通过（项目当前命令为 TypeScript 类型检查）。
- `npm run build`：通过；仍有已有的静态/动态重复导入和大分包警告，不声称消除了这些警告。
- 本地真实浏览器，以合成数据挂载实际 Vue 分析/类型组件：核对184个分类选项、重复子分类禁用、同类别不同子分类可继续、Tandem 可选，中英文无控制台错误/警告。该组件验收不是完整生产会员链路或生产样式验收。
- 未调用付费模型，未访问真实用户稿件或扣会员学分。未宣称真实 LLM 输出已完全遵守新规则。
- 精简检查：移除本次更新后不再可达的类型指南分支与重复旧模板；保留实际共享的年度规则和现有兼容导出，不新增推测性扩展层。

独立工作目录使用已安装的同一套 `node_modules` 验证，`package.json` 和 `package-lock.json` 均与基线主分支一致，没有纳入原工作区的锁文件修改。2026-10-29 `npm audit --omit=dev` 非零退出，报告既有依赖7项 high、1项 critical（DOMPurify）；本增量不宣称安全审计通过。生产发布前须单独排查实际可达性及修复依赖，不能把已有告警当成无风险或在本年度规则 PR 中静默升级包。

## 部署影响与上线卡片

**Supabase：无需迁移。Vercel：需要部署。Cloudflare Worker：需要重新构建并部署。** 原因是共享规则被服务端盲审/Jev预筛导入，同时 Vue、公共指南和语言资源有变更。无新增依赖、环境变量、上线开关或计费规则。

安全顺序：审核并发布同一个目标提交 → Vercel 后端候选/晋升 → 从该提交执行 `npm run build` → `npx wrangler deploy`。按[部署 runbook](../DEPLOYMENT_RUNBOOK.md)核对项目、环境和提交 SHA；不要仅对旧 deployment 点 Redeploy，也不要在混有其他未审核改动的 checkout 发布。

上线后验收：站点投稿链接指向2027；显示750/40/100与125字符规则；主/次分类可手动修正、关键词可撤销；Tandem 可选、Registered 不在新选择中；Clinical Synopsis 非结构化；旧浏览器缓存更新；盲审与生成使用2027规则。经用户授权的测试账户再验证会员/BYOK分析→生成、实际模型披露和原有学分行为。付费烟测需另行明确账户和扣费授权。

本轮实际生产操作：**无**。未执行迁移、Vercel 部署、Worker 部署或付费烟测。2026-10-29 用户授权将本增量独立提交、push 并创建 PR；该授权不包含生产部署。统计图代码、容器配置及未审核的依赖修改不纳入本 PR，也不启用该入口。

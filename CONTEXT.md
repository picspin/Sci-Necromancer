# Sci-Necromancer

Sci-Necromancer helps researchers prepare conference submissions and scientific visuals while making the limits of AI assistance explicit.

## Language

**Documentation Assistant (炼气师 / Sci Guide)**:
A public conversational guide that helps visitors understand and troubleshoot Sci-Necromancer without requiring membership.
_Avoid_: General-purpose chatbot, paper-writing bot, Doc Bot

**Help Shortcut**:
A curated answer or deep link that resolves a common product question without invoking an AI model.
_Avoid_: AI answer, generated FAQ

**Assisted Answer**:
An AI-generated product-support response used only when Help Shortcuts and documentation do not resolve the visitor's question.
_Avoid_: Generation task, abstract generation

**Help Article**:
A version-controlled, linkable source of truth for one Sci-Necromancer feature or troubleshooting topic.
_Avoid_: Knowledge-base record, vector document, support post

**Guided Navigation**:
An allowlisted interface action that opens, focuses, or highlights a destination without changing user data or settings.
_Avoid_: Agent action, automated configuration
